# Decision Journal — FEM course project (crackfem)

One dated line per non-obvious decision: what was chosen, why, what was rejected. Never delete old entries.

## 2026-10-07 — Design (brainstorming, approved in chat)

- **Baseline = the approved proposal** (15 Sep 2026, "Crack-Width-Informed Deflection, CPK72 S01", approved without comments). It supersedes the older "no direction selected / Modeler-vs-Detective LLM benchmark" notes in the exported project memory.
- **Authorship: Claude writes the code, the student reviews** (student's choice). The report states this plainly and includes the student's review notes. Rejected: student-writes-first (no time before the 19 Oct final) and a split ownership.
- **Prestressed stand-in girder instead of the proposal's RC rectangle**, because a 24.5 m highway span is typically a precast PC I-girder and the BRB-CP drawings are not available. Candidate: AASHTO Type IV, locked in B1. Rejected: keeping RC (wrong physics if the girder is PC).
- **Approach A — inverse for remaining prestress η from crack width.** A crack visible at rest in a PC girder means precompression is gone, so η is the meaningful unknown. Rejected: B forward-only w → Ma → Ie (no real nonlinearity; overload is a weaker explanation) and C continuous spans (no evidence the spans are continuous).
- **Grillage of the S01 deck, staged after a 1-D girder.** On a simply supported span M comes from statics, so the proposal's iteration ends after one pass and FEM would only post-process deflection (fails the "spreadsheet test"). A grillage is indeterminate, so FE sits inside the nonlinear loop and the inverse loop. Rejected: 1-D only (FEM is decoration) and 2-D CST girder (crack modelling too heavy for the time).
- **EC2 family for both crack width (§7.3.4) and stiffness (§7.4.3); ACI Branson/Bischoff kept as a cross-check.** One code family keeps the two steps consistent and EC2 has an explicit prestressed crack-width form that inverts in closed form. Rejected: ACI as main (proposal's choice) — mixing families and no equally explicit prestressed crack-width formula.
- **Damage is per element from its own moment, not forced into one element** — fixes the mesh dependence of the proposal (damaged length = L/N).
- **ML surrogate dropped** (was the proposal's future work): a solve costs milliseconds, so a surrogate adds nothing. Evidence = measured timing in the report.
- **Paywalled standards replaced by open secondary sources tagged [secondary]** (student's choice). Rejected: waiting for originals from the library.
- **New dependencies approved: matplotlib (figures) and PyNiteFEA (independent grillage cross-check), pinned.**
- **Hand-in = GitHub repo link** (push is a gate, public vs private decided then). Only synthetic masks and their outputs from the thesis pipeline enter the repo; no field data, URLs or keys.
- **Default cracked girder = exterior G1 (more exposed to drainage — inference), interior G3 as a second case.**

## 2026-10-07 — B1 source pack

- **barrier_weight changed from 7.0 kN/m to 0.326 kip/ft (4.76 kN/m)** — source S02, the TxDOT T501 rail weight of 326 plf per side (TTI 0-4751-1 Vol. 2, p. A.1-3); the old 7.0 kN/m had no source.
- **unit_weight_concrete changed from 24.0 kN/m³ to 0.150 kcf (23.56 kN/m³)** — source S11, the AASHTO value used in the TxDOT/TTI Type IV example; keeps dead load in the same AASHTO family as the HS20-44 live load. Rejected: EN 1991-1-1 25 kN/m³ (JRC EUR 25193) and JRA 24.5 kN/m³ (JICA 2000).
- **unit_weight_wearing changed from 22.0 kN/m³ to 0.140 kcf (21.99 kN/m³)** — source S11, same document; 22.0 was a rounded conversion, now stated in the source's own units.
- **Type IV fixture uses NCDOT I = 260,741 in⁴** (S03), not PCI 260,730 or TxDOT 260,403, because it equals the exact integral of the params outline (260,740.6 in⁴); PCI is rounded, and the TxDOT section has a slightly different shape.
- **ec2_crack_example uses Ecm = Es/15 = 13.33 GPa** (S21a), because the ECP example states the modular ratio αe = 15 instead of Ecm; Ac,eff = λ·b·h with the printed λ = 0.2012. Rejected: a real C30/37 Ecm (33 GPa), which would not reproduce the printed wk.
- **pc_cracked_example set to null** (S21b): Mast (1998) Example 1 matches every other requirement and was checked (c = 17.26 in reproduced), but it prints the decompression stress fdc = 162 ksi, not fpe at zero moment. Putting a derived fpe (151.8 ksi) in the fixture would break the "printed values only" rule. Rejected: deriving fpe; assuming fpe = fdc (wrong physics for the test).
- **HS20-44 × 1.30 (JICA 2000, "DOH standard") not applied** (S12): one international-bridge project, not the BRB-CP design basis; left as an open question for the student.
- **ξ = 0.6 for pretensioned strand kept, marked unverified** (S09): no open source printing the Table 6.2 pretensioned row was found; the post-tensioned row (0.5) is confirmed by Sétra (2007).
- **pc_cracked_example now filled from Mast (1998) Example 1, using fdc (supersedes the null entry above)** (S21b): the model's εp0 is the strand strain at zero concrete strain, which is exactly the paper's decompression stress, so εp0 = fdc/Ep needs no derived fpe. strand_stress_MPa stays null because the total (162 + 9.97 ksi) is never printed as one number.
- **β = 0.5 in EC2 7.4.3 (spec §5.2 corrected from 1.0)** — a bridge girder carries sustained dead load and repeated truck load; S10 gives 0.5 for both. Rejected: 1.0 (single short-term loading only).
- **Mast 1998 strand stress left null in the fixture** — the paper prints fdc and Δfps separately, never their sum; the neutral-axis depth is the printed check. Rejected: summing two printed values.
- **Lump-sum loss 45 ksi kept**, evidenced as ACI 343R-88 Table 9.6.4.1; its AASHTO Table 9.16.2.2 attribution is unverified (S06).
- **Cracked mode means "concrete carries compression only" anywhere in the section**, so under prestress alone a section whose strand is below the kern cracks at the top; the reference curvature kappa(0) for secant stiffness and camber is therefore always taken from the uncracked state. Rejected: restricting cracking to the soffit side (extra rule, no benefit in the sagging region used here). Found by the implementer of Task 7: the plan's test compared modes at 50 kN·m, outside the window where they can agree.

## 2026-10-12 — Student decisions (staging, live-load factor)

- **Staged construction adopted** (student): stage A (prestress + girder + wet slab) on the bare girder, stage B (wearing surface, barriers, truck) on the composite girder; the slab carries the stage-A strain plane as locked-in strain, and secant stiffness is measured from the end of stage A. Reason: the G04 reviewer estimated that a single-stage model shifts the soffit-decompression η by about 0.15 (0.68 staged vs 0.53 single-stage), comparable to the measurement band. Rejected: single-stage with a stated limitation. Plan 1 amended (Tasks 9, 11, 12, new 15b, 16, 20, 21).
- **HS20-44 × 1.30 applied** (student; supersedes the B1 line that left it unapplied): JICA 2000 Table 3.1 gives "DOH standard (AASHTO HS 20-44x1.30)" for main girders, so the stand-in girder is designed and checked for the DOH design truck. Implemented as `live_load_factor = 1.30` (S12) in Task 12.
- **Unloading rule: M <= M_ref uses the uncracked stiffness EI_I.** Harmless on the 1-D girder (stage-B moments are positive everywhere); to be revisited for the grillage, where remote girders can see M_B ≈ 0 and would jump between EI_I and the cracked tangent.
- **EC2 zeta uses Mcr/M on total moments** (allowed for flexure); for prestressed sections this gives somewhat more tension stiffening than the Δσp ratio would. Kept for Stage 1; stated in the report.
- **Grillage (Plan 2) convergence risk noted:** with β = 0.5 an element crossing the sound Mcr inside the secant loop sees a stiffness jump; Plan 2 will make the pre-cracked flag sticky once crossed, cap iterations and report non-convergence.
- **Tornado perturbs the bond factor ξ (0.5–0.7) instead of kt**: the G05 review showed the 0.6·Δσp floor governs for all realistic widths, so kt, fct,eff and αe do not affect w; ξ is unverified (S09) and sets sr,max ∝ k1/ξ, so it is the material uncertainty that matters.
- **Truck scan includes the exact kink placements** (each axle at midspan or at a support) in addition to the 1 mm grid, because the midspan moment is piecewise linear in truck position and peaks at a kink the grid can miss (found in Task 12: 1,582,033 vs 1,582,037 N·m).
- **Task 13 test corrections:** one-pass round-off bound 1e-9 (1e-12 was below this machine's noise floor) and vertical-reaction sum R[0::2] (the plan summed a moment reaction into a force check).
- **Stage 1 girder uses interior-girder rules** (tributary width S, S/5.5 distribution), so the 1-D results represent an interior girder; the exterior girder G1 (default cracked girder) is handled by the grillage in Plan 2, where the lever-rule/overhang differences appear naturally.
- **Truck placed for maximum midspan moment** (the crack and Mcr checks are at midspan). The reviewer measured that this placement underestimates the maximum midspan live-load deflection by 1.9% and the absolute maximum moment by 0.1–0.4%; stated in the report next to the L/800 check.
- **Secant iteration also checks the stiffness residual** before stopping (reviewer showed a moment-only criterion can stop with an EI belonging to other moments when stiffness jumps at Mcr); Plan 2 adds the sticky pre-cracked flag as the cure for 2-cycles.
- **Inverse hardening** (G08 review): decompression edge by bisection (24 vs 83–180 evaluations), residual check after Illinois (a forward-model jump must not yield a fake point estimate), w_meas ≤ 1 nm treated as no crack, NaN guards. Plan 2 (expensive grillage forward model): cache the plateau edge per model so widths below it cost zero solves.

## 2026-10-12 — G09 review

- **Staging shift corrected (supersedes the ≈0.15 quoted above):** with the adopted model, staging moves the soffit-decompression η under dead load by +0.06 (each model designed for zero tension: 0.588 vs 0.526, 30 vs 28 strands) or +0.10 (same 30-strand girder analysed single-stage: 0.588 vs 0.489); the inverse's no-crack edge moves by +0.04 / +0.08, and η inferred from a 0.05–0.3 mm crack by ≤ 0.04. The 0.15 (0.68 vs 0.53) came from keeping 28 strands in the staged model (+1.07 MPa soffit tension under service) and applying η to the bare-girder prestress (loss before casting). Staging kept: it is the real construction sequence and costs nothing at run time. Checked independently by the reviewer with exact trapezoid integrals.
- **Pre-cracked zone uses the moving-truck moment envelope** (up to 1.31× the midspan-placement moment off midspan); truck deflection still uses the midspan placement. Effect on the truck deflection (EC2, 40 elements): η = 0.7: 15.2 → 17.2 mm (pre-cracked elements 6 → 10); η = 0.55: 37.7 → 39.1 mm (15 → 18); η = 0.407: 64.7 → 65.2 mm (21 → 22); η = 0.3: 76.8 → 78.6 mm (23 → 26); η = 1 unchanged (9.5 mm, none pre-cracked).
- **Compression zone in the slab:** for hc,ef the bottom of the compression zone is taken from the mechanical strain when the total-strain zero lies outside the girder (staged sections at very low η).
- **L/800 is compared with the truck deflection only**, which uses the moment distribution fraction S/5.5 and ×1.30 (AASHTO deflection checks often share all lanes equally, ≈0.4 truck per girder) — stated in the report.
- **Limitations to report:** differential deck shrinkage (≈+0.5–0.7 MPa at the soffit, Δη ≈ 0.02–0.05) and placing all losses before casting (≈0.02) are not modelled; each is about as large as the staging shift.
- **Monte Carlo conventions** (G10 review): σ = u/2 (k = 2 reading of ClaimBridge's ±2·GSD; 1.96 would widen the band 2%); truncated-normal sampling by inverse CDF (no rejection loop; common random numbers across cases); percentiles from ok samples with dropped statuses reported and a censored flag above 5%; band reported as p05–p95 of η from measurement noise only; deflection percentiles from η percentiles in reversed order (deflection is monotone in η — reviewer checked 981 points).
- **Synthetic scenarios: η_dec − 0.10 / 0.20 / 0.35** (the third was added after review so that one case is measurable at GSD 0.10: η_true = 0.21, w = 0.409 mm → 20 / 8 / 4 / 1 px at GSD 0.02 / 0.05 / 0.10 / 0.38; 0.30 was avoided because it sits on the 3 px gate at GSD 0.10). Findings: at GSD 0.38 mm/px nothing is measurable for this girder (gate 1.14 mm > the model's largest width 0.89 mm); a refusal still bounds η from below through the 3 px width (η ≥ 0.44 / 0.37 / 0.27 at GSD 0.02 / 0.05 / 0.10); the rule-engine rating is 5 "Excellent" for any width ≤ 5 mm (4 at 5.5 mm), so it carries no information about prestress. The synthetic masks test plumbing and gates, not measurement accuracy (straight constant-width bars; the same model forward and inverse).
- **Parser fails closed and unresolved cracks block a governing width** (field-survey safety). A crack with neither a width line nor a REFUSED line (e.g. a changed report format) raises instead of being skipped; a crack with gate "no-valid-points" (or any gate the bridge does not know) makes `governing_width` return None, because an unresolved crack may be the widest one and reporting the widest measured crack would bias w low, i.e. η high (unconservative). Cracks refused only as narrower than the minimum measurable width cannot exceed the measured ones and do not block. `run_pipeline` raises RuntimeError with the pipeline's stderr (timeout 120 s) and resolves relative input paths, and the saved raw reports keep only the lines the parser recognises, with a check that no local path is written.
- **run_all reports a refusal as a lower bound on η** (the η whose predicted width equals the 3 px gate) and uses the first detectable case (finest GSD, least damage) as the reference η for the figures (Task 21 amended after the G11 review).
- **Tornado holds the as-built strand count** (30; `Girder1D(inp, n_strands=30)`): an existing girder does not get new strands when an input is perturbed. Re-designing per perturbation understated the sensitivities (girder spacing swing 0.036 → 0.082, strand centroid 0.029 → 0.049, slab thickness 0.014 → 0.029; case2_gsd0p02). The re-designed variant is kept in results (`tornado_redesigned`) for the record.
- **Refusal bounds reported twice:** nominal (width < 3 px: η ≥ 0.439 / 0.368 / 0.272 at GSD 0.02 / 0.05 / 0.10) and one-sided 95 % with σ = 1 px, the Monte Carlo convention (width < 4.645 px: η ≥ 0.411 / 0.313 / 0.179); none at GSD 0.38 (gate wider than the model's largest width). Deflection bands stored in explicit reversed order (`deflection_*_band_mm`: p05 from η p95, p95 from η p05); results JSON is strict (non-finite → null, `allow_nan=False`).
- **Figures made honest** (G12 review): fig1 shows η_true against the MC band at the measured width instead of points that lie on the curve by construction, with η_dec and the 3 px gate widths; fig2 does not draw the EC2 ζ jump at Mcr as a slope (line broken at the exact Mcr); fig7 shows refusal bounds; fig6 shows relative convergence (|δ_N − δ_160| / δ_160) instead of two flat lines; fig8 is the as-built tornado with the tested ranges in the labels.

## 2026-10-12 — Plan 1 close-out (Task 22)

- **Pre-cracked zone rule:** an element whose total service moment has exceeded Mcr(η) is pre-cracked: its concrete tensile strength is taken as zero, so its effective Mcr is the decompression moment (a crack that traffic has opened carries no tension on the next load). Rejected: the sound fctm in every element, which would let a traffic-cracked element regain its tensile strength. The service moment is the moving-truck envelope (G09 line above).
- **Dead-load and service moments computed once on the determinate girder:** stage A from statics, stage B from one linear FE solve with the uncracked EI; on a simply supported span they do not depend on stiffness (the one-pass secant test proves it), so w_pred(η) costs one section solve, not an FE solve. Rejected: an FE solve per η (same answer, slower). Plan 2 puts the FE solve back inside w_pred, because grillage moments do depend on stiffness.
- **Illinois as the safeguarded secant** (spec §5.4): secant steps that always keep the root bracketed, so the kinks in w_pred(η) cannot throw the iterate outside [0.02, 1]. Rejected: plain secant (can leave the bracket), Newton (needs dw/dη, which jumps at the kinks), bisection alone (slower; kept only for the no-crack edge, where w is flat at zero).
- **GSD set 0.02 / 0.05 / 0.10 / 0.38 mm/px:** 0.02 and 0.05 for a close-range photo, 0.10 in between, 0.38 the lower end of the thesis pipeline's field GSD, so the set runs from "measurable" to "refused" and shows where the 3 px gate bites.
- **Held-out cracked-zone check deferred to field data** (spec §5.4): the synthetic masks are drawn from the same model, so comparing the predicted visible crack zone with the mask would be circular; `visible_crack_zone_m` is reported as a model output until field images exist.
- **Cracked-section check = textbook RC closed form + the S21 prestressed example** (Mast 1998 Ex. 1, found in B1), so the plan's allowed "S21 skip" never occurs; the 3 skips in `pytest -q` are the tests that call the private pipeline.
- **Reading guide maps `f_eq` to the Ch3 slides' {f0} with the same sign** (supersedes the plan convention "f_eq = −F0"): slides 3-8 to 3-10 define {f0} = ∫[N]ᵀ w dx (work-equivalent loads, −wL/2, −wL²/12, −wL/2, +wL²/12 for a downward w) and {f} = [k]{d} − {f0}, as Logan (5th ed.) Eq. 4.4.11 does; the plan assumed the slides' F0 were fixed-end forces. The code already matches the slides; nothing changed in src/.
- **Logan page references verified** against the 5th edition text (book page = PDF page − 19): §4.1 pp. 155 and 157, §4.2–4.3 pp. 161–164, §4.4 pp. 177–179, Table D-1 p. 753. Only pages found this way are cited.

## 2026-10-15 — Plan 2 design (Stage-2 grillage, B4–B5; controller-approved list, plan-writing probe)

- **Grid element = Logan §5.4** (Eqs. 5.4.16–5.4.19): 3 DOF per node in Logan's order (w, θx, θz), bending block = the Stage-1 `beam_k` on (w, θz), torsion GJ/L, [T] per node [[1, 0, 0], [0, C, S], [0, −S, C]]; checked against a sympy derivation and Logan (5th ed.) Example 5.5 (pp. 244–250, printed answers in `tests/fixtures/published.json`). Rejected: a 3-D frame element (the in-plane DOFs of a grid carry nothing).
- **Deck model:** 5 girder lines at 2.2 m with the same longitudinal mesh as the girders; slab strips at every girder station with tributary width (Hambly: I = b t³/12, J = b t³/6, S23); end and midspan diaphragms; overhang. Rejected: strips at a coarser spacing than the girder nodes (loads and moments would need interpolation between stations).
- **Mesh n_el = 20:** probe convergence study (strand counts held): w_pred at η = 0.36 within 0.03 % of N = 80 for G1 and G3; damaged service deflection of G1 within 0.6 % (the moving-truck envelope that sets the pre-cracked zone is resolved on the element grid). N = 40 costs 4× the build time for no visible change. The study is rerun in Task 12.
- **Diaphragm = its web alone** (1.10 × 0.25 m, slab concrete, S27) added to the slab strip of its station, not a T section with the strip as flange. Reason: the probe showed the T-section diaphragm's stiffness depends on the mesh (the flange is the strip width L/n_el), and G1's w_pred drifted by 3 % per mesh doubling with it; with the web alone the result is mesh-independent. A non-composite diaphragm is a lower bound on its stiffness (stated).
- **Overhang 3.0 ft and barrier width 1.0 ft** from the TxDOT/TTI Type IV example (S25, the source of S02), instead of a free 1.0 m: the same example family as the other deck stand-ins. With the 2 ft curb rule the outer wheel line then lies exactly over G1 at the curb position.
- **Member properties:** girder longitudinal EI from the Stage-1 section models of a composite girder with its own slab width (exterior S/2 + overhang = 2.01 m, interior S = 2.2 m); girder GJ = G_girder × J_TypeIV + G_slab × b t³/6 (girder plus slab, St Venant; J_TypeIV = Σ b t³/3 over bottom flange, top flange and web, haunches left out, Logan Eq. 5.4.15 and Table 5-1, = 14,336 in⁴); G = Ecm/2(1 + ν) with ν = 0.2 (EC2 3.1.3(4), S24). Cross members and torsion stay linear (uncracked).
- **Stage A per girder by statics** exactly as Stage 1, each `Girder1D` built with `girder_spacing` = its slab width, so the exterior girder carries its own girder and slab tributary. The wet-slab overhang's torque on the bare exterior girder is not modelled (stage A is vertical statics).
- **Stage-B dead load as girder line loads by the lever rule**, cut at the girder lines (exact force and moment), with the overhang part and the barriers as a line torque on the exterior girders turned into consistent nodal moments. Rejected: nodal loads at the stations (statically equal, but the moment inside each girder element would lose its parabolic part).
- **Truck: wheel loads, no distribution factor.** HS20-44 × 1.30 × (1 + I), each axle split into two wheel lines 6 ft apart, wheels 2 ft inside a 10 ft clearance width that stays between the curbs (S26). Wheel lines between girders go to the two adjacent girder lines by the lever rule, then act as point loads on the girder members (consistent loads). Longitudinal position = the Stage-1 placement for maximum midspan moment.
- **Deviation from "the truck" (singular): one truck and two trucks side by side are scanned** (two design lanes: roadway 10.02 m, floor(w / 12 ft) = 2; clearance widths may not overlap; every placement also mirrored). Reason: Stage 1's S/5.5 is the AASHTO factor for two or more lanes loaded, so a one-truck grillage would not be comparable; in the probe two trucks govern G1. The critical placement of each girder (largest midspan stage-B truck moment on the linear intact grillage, by superposition of one solve per girder line) is held fixed for every η: a crack does not move the truck.
- **Nonlinear grillage:** every girder element gets the Stage-1 rule (staged section, EC2 secant EI from M_ref = its own stage-A moment); the cracked girder Gk has η < 1 and the others η = 1, so a neighbour that cracks under the shed load is handled by the same rule (the probe found G2 cracking when G1 is at η = 0.36). Sticky pre-cracked flag inside an analysis; stiffness-residual check; under-relaxation available (`relax`); iteration cap 100; a non-converged analysis is returned with its history (`SecantResult.converged = False`) and makes w_pred NaN, which the inverse refuses. Sensitivity: GJ of cracked girder elements × 0.5 (one run per cracked girder at its reference η).
- **Initial pre-cracked zone from a linear intact envelope:** stage A + stage-B dead + the moving truck at the girder's critical placement (each axle at every node and element midpoint, both directions), compared with Mcr(η). Rejected: a nonlinear moving-truck envelope per η (hundreds of nonlinear solves per w_pred). The envelope over-estimates the cracked girder's truck moment (it ignores its own shedding), so it errs toward more pre-cracking.
- **Strand design per girder:** the Stage-1 zero-tension rule under each girder's own grillage service moment at η = 1 (stage A + stage-B dead + its critical truck), iterated until the counts stop changing; probe (31, 29, 27, 29, 31) in two rounds. Rejected: 30 strands everywhere (G1 would have soffit tension at service, the interior girders a different margin than the rule gives, and η would not mean the same thing for G1 and G3).
- **Cracked girders:** G1 (index 0, exterior, default) and G3 (index 2, interior), as in the spec §5.4.
- **Inverse and Monte Carlo through a table:** w_pred on a 99-point η grid (0.02–1) plus the plateau edge (bisection on the exact map), linear interpolation; `uq.monte_carlo_eta` (2,000 samples, σ = u/2, same seed) runs on the table unchanged; p05/p50/p95 are confirmed by the exact `estimate_eta` at the widths the table maps them to; the point estimate is exact. Rejected: Monte Carlo on the exact map (about 25,000 nonlinear solves per case). The data (`data/claimbridge/*_spike.json`) and the inverse/uq code are reused unchanged.
