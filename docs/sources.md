## Notes on rows where sources disagree or need explanation

(S21 note revised 2026-10-07: the cracked prestressed example is now in the fixture using fdc.)

**S03 — Type IV second moment of area.** Three open tables give three values:
- PCI BDM p. B-7: A = 789, yb = 24.73, I = 260,730 in⁴.
- NCDOT Fig. 6-66: A = 789.0, yb = 24.73, I = 260,741 in⁴.
- TxDOT/TTI 0-4751-1 Vol. 2, Table A.1.4.1 (from the TxDOT Bridge Design Manual 2001): A = 788.4, yb = 24.75, I = 260,403 in⁴.

The fixture uses the NCDOT values. The exact integral of the trapezoid outline in `params.py` gives A = 789.0 in², yb = 24.734 in, I = 260,740.6 in⁴, so NCDOT matches the outline to the last digit. The PCI value looks rounded to the nearest 10 in⁴ (difference 4·10⁻⁵, inside the planned 2·10⁻³ test tolerance). The TxDOT section is a slightly different shape (0.6 in² less area) and is not modelled.

**S05 — Ep.** EC2 recommends 195 GPa for strand (used). The Bekaert datasheet gives a nominal 28.5 Mpsi (196 GPa). The AASHTO Standard Specifications value used by TTI (p. A.1-3, STD Art. 9.16.2.1.2) is 28,000 ksi (193 GPa). The spread is 1.5 % and is not material here.

**S10 — β.** The sources give β = 1.0 for single short-term loading and 0.5 for sustained or repeated loading. `params.py` uses 0.5. Design spec §5.2 said "β = 1.0 (short-term)" (resolved 2026-10-07: spec corrected to β = 0.5). The inspection state is sustained dead load, so 0.5 fits it. A truck pass is short-term (1.0). Which one each load state uses is a modelling decision still open; no value was changed (resolved 2026-10-07: spec corrected to β = 0.5).

**S11 — Unit weights.** Three families disagree:
- AASHTO, as used by TxDOT/TTI: concrete 150 pcf = 23.56 kN/m³, asphalt 140 pcf = 21.99 kN/m³.
- EN 1991-1-1, as used by JRC EUR 25193: reinforced concrete 25 kN/m³, asphalt 25 kN/m³.
- JRA, as used by JICA (2000) for the Thai–Lao Mekong bridge: prestressed concrete 24.5 kN/m³, asphalt 22.5 kN/m³.

The AASHTO values are used because the live load, impact and distribution rules (S12–S14, S17, S18) are all AASHTO Standard Specifications, so dead and live load stay in one family. The old 24.0 kN/m³ matched none of them.

**S12 — DOH design truck.** The JICA (2000) design table lists the DOH standard for main girders as AASHTO HS20-44 × 1.30. That is one project (an international bridge, design standard JRA), so it is evidence that DOH practice may scale HS20-44, not proof that BRB-CP (1995) was designed that way. `axle_loads` stays at plain HS20-44 (8/32/32 kip). The × 1.30 was applied by the student's decision of 2026-10-12 (`live_load_factor = 1.30`).

**S21 — worked examples.**

(a) ECP Example 7.3: plain RC, single bar size, short-term load, so ξ = 1. Printed inputs, converted to SI:
- k1 = 0.8, k2 = 0.5, k3 = 3.4, k4 = 0.425 (printed "k1k2k4 = 0.17"), kt = 0.6.
- fct,eff = fctm = 2.9 MPa, Es = 2·10⁵ MPa, c = 40 mm.
- As = 2712 mm² (6φ24), so φ = 24 mm.
- σs = 234 MPa, b = 400 mm, h = 600 mm.
- The example states αe = 15, not Ecm, so the fixture uses Ecm = Es/αe = 13.33 GPa (the crack-width formula uses only the ratio).
- Ac,eff is not printed as a number. The example prints hc,ef/h = λ = 0.2012, so Ac,eff = 0.2012 × 400 × 600 = 48,288 mm².
- Printed result: wk = 0.184 mm. sr,max is not printed as a separate number, so `sr_max_mm` = null.
- Recomputed with the EC2 formulas: ρ = 0.05616, σs,cr = 57.08 MPa (printed 57.08), sr,max = 208.65 mm, εsm − εcm = 8.846·10⁻⁴, wk = 0.1846 mm.

(b) Mast Example 1: rectangular 12 × 32 in, twelve 1/2-in strands (Aps = 1.836 in²), dp = 26 in, Ec = 4415.2 ksi, Ep = 28,500 ksi. Printed results:
- prestress level "fdc = 162 ksi (1117 MPa)";
- M = 6392 in-kips (722 kN·m);
- neutral-axis depth c = 17.26 in (438 mm);
- fc,top = 3.048 ksi;
- Δfps = 9.97 ksi (68.8 MPa), so the strand stress is 162 + 9.97 = 171.97 ksi.

Recomputed by strain compatibility: c = 17.262 in, fc,top = 3.048 ksi, σp = 171.96 ksi.

The paper's prestress input is the decompression stress fdc, defined as the strand stress when the adjacent concrete has zero stress. That is exactly the model's locked-in strain definition, so the fixture uses εp0 = fdc/Ep and needs no derived fpe. (The equivalent fpe at zero moment on the gross section, 151.8 ksi, is not used.) The section is a single concrete with one strand layer and no mild steel, so the fixture schema expresses it fully.

Fixture values (printed, converted to SI only):
- parts = [[0, 0.8128, 0.3048, 0.3048]] m (12 × 32 in rectangle);
- d_p = 0.6604 m (26 in), A_p = 1.18451·10⁻³ m² (1.836 in²);
- Ec = 30.44 GPa (4415.2 ksi), Ep = 196.5 GPa (28,500 ksi);
- fdc = 1116.95 MPa (162 ksi; printed SI 1117 MPa);
- M = 722.2 kN·m (6392 in-kips; printed SI 722 kN·m), all loads except prestress;
- neutral-axis depth = 0.438404 m (17.26 in; printed SI 438 mm).

`strand_stress_MPa` is null: the paper prints fdc = 162 ksi and Δfps = 9.97 ksi separately but never their sum (171.97 ksi = 1185.7 MPa) as one number. The printed Δfps = 9.97 ksi (68.74 MPa) is used instead as the Δσp check (`delta_sigma_p_MPa`), because it is the strand stress change from zero concrete strain, exactly the model's `delta_sigma_p`.
